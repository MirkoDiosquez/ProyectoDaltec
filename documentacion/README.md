# Documentación del proyecto

Esta carpeta reúne la documentación general para entender el sistema de forma amigable y clara.

## Archivos disponibles
- [InfoGeneral.md](InfoGeneral.md): descripción del proyecto, propósito y funcionalidades.
- [Arquitectura.md](Arquitectura.md): explicación de la estructura del sistema y cómo correr sus partes.
- [Funciones.md](Funciones.md): descripción del funcionamiento de las funciones y métodos principales.

## Propósito
La documentación está pensada para que cualquier integrante del equipo pueda:
- entender de qué trata el sistema
- conocer cómo está dividido arquitectónicamente
- comprender las principales funciones del código
- seguir con más facilidad el desarrollo y mantenimiento del proyecto

## Recomendación
Se sugiere mantener esta documentación actualizada cada vez que se agreguen módulos, nuevos endpoints o cambios importantes en la lógica del negocio.
